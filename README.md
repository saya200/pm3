# الشعبة الثالثة — منصة تنبيهات دبلوم عالي إدارة المشاريع

لوحة مشتركة للشعبة: أي طالب ينشر واجبًا/اختبارًا/مناقشة/إعلانًا خلال ثوانٍ ← يظهر فورًا على أجهزة الجميع ← عد تنازلي حي حتى الموعد ← إشعارات تذكير ← نقاش محفوظ تحت كل تنبيه ← أرشفة تلقائية بعد انتهاء الموعد.

## الـStack ولماذا

| الجزء | الاختيار | السبب |
|---|---|---|
| الواجهة | React + TypeScript + Vite (PWA) | موقع ثابت خفيف، يُثبَّت على الجوال كتطبيق |
| الاستضافة | GitHub Pages | مجاني وبدون سيرفر |
| البيانات والتزامن الحي | Cloud Firestore | تزامن لحظي بين الأجهزة + كاش محلي يعمل بدون اتصال |
| الهوية | Firebase Anonymous Auth | **بدون حسابات ولا كلمات مرور**؛ فقط هوية مجهولة للجهاز حتى يعرف "صاحب التنبيه" |
| الصور | تُضغط في المتصفح (≤1280px JPEG) وتُخزن في Firestore | يبقى المشروع على الخطة المجانية (Firebase Storage يتطلب الآن خطة مدفوعة) |
| الإشعارات | Firebase Cloud Messaging + سكربت مجدول على GitHub Actions كل 10 دقائق | مجاني بالكامل، بدون Cloud Functions (التي تتطلب خطة Blaze) |

كل شيء يعمل على **الخطة المجانية (Spark)** لـ Firebase، وهي كافية بسهولة لشعبة من ~50 طالب.

## التشغيل محليًا (بدون مشروع Firebase حقيقي)

يتطلب: Node 22، Java 21، و `npm i -g firebase-tools`.

```bash
npm install
cp .env.example .env.local        # واجعل VITE_USE_EMULATORS=1
npm run emulators                  # نافذة 1: محاكي Firestore + Auth
npm run dev                        # نافذة 2: الموقع على http://127.0.0.1:5173/s/<SECTION_SLUG>/
node scripts/seed-emulator.mjs     # (اختياري) بيانات تجريبية + كود إدمن: test-admin-code-123
```

## الإعداد لأول مرة (مرة واحدة فقط)

### 1) مشروع Firebase
1. أنشئ مشروعًا في [console.firebase.google.com](https://console.firebase.google.com) (الخطة المجانية).
2. **Firestore Database ← Create database** (Production mode). الموقع المقترح: `me-central2` (الدمام).
3. **Authentication ← Sign-in method ← Anonymous ← Enable**.
4. **Project settings ← General ← Add app ← Web**: انسخ القيم (apiKey, authDomain, projectId, appId, messagingSenderId).
5. **Project settings ← Cloud Messaging ← Web Push certificates ← Generate key pair**: انسخ المفتاح (VAPID).
6. **Project settings ← Service accounts ← Generate new private key**: ملف JSON (سري — لا ترفعه للمستودع).

### 2) اختر رابط الشعبة العشوائي
أي نص عشوائي بأحرف إنجليزية صغيرة وأرقام، 10 خانات أو أكثر، مثلًا:
```bash
node -e "console.log(require('crypto').randomBytes(6).toString('hex'))"   # مثال: 3f9a1c7e22b4
```

### 3) GitHub (مرة واحدة)
- **Settings ← Pages ← Source: GitHub Actions**.
- **Settings ← Secrets and variables ← Actions ← New repository secret**، أضف:
  - `SECTION_SLUG`: الرابط العشوائي.
  - `FIREBASE_SERVICE_ACCOUNT`: محتوى ملف JSON لحساب الخدمة كاملًا.
  - `ADMIN_CODE`: كود الإدمن (8 خانات أو أكثر، ويفضّل أطول).
- إعدادات Firebase العامة موجودة أصلًا في `.env.production` (ليست أسرارًا).

عند كل دفع للفرع الافتراضي، سير العمل `deploy.yml` يقوم تلقائيًا بـ:
نشر قواعد الأمان والفهارس على Firebase ← ضبط كود الإدمن ← بناء الموقع ← نشره على:
**`https://<user>.github.io/<repo>/s/<الرابط-العشوائي>/`** — هذا هو الرابط الذي ترسله للشعبة.

الصفحة الرئيسية للمستودع على Pages (بدون المسار) تعرض فقط "الرابط غير مكتمل" ولا تكشف الرابط.

> المستودع يجب أن يكون **عامًا** لتعمل GitHub Pages مجانًا، ودقائق Actions للمستودعات العامة غير محدودة (مهم لأن سكربت الإشعارات يعمل كل 10 دقائق). لا توجد أسرار في الكود.

## الإدمن
- التفعيل: رابط `.../s/<الرابط>/?admin=<الكود>` مرة واحدة على جهازك (يُحذف الكود من شريط العنوان فورًا)، أو من أسفل الصفحة ← "الإدمن".
- الصلاحيات: تعديل/أرشفة/حذف أي تنبيه، قسم "المحذوفة" (استعادة أو حذف نهائي)، حذف الردود، ومراجعة ما علّمه الطلاب "مكرر محتمل".
- **تغيير الكود**: غيّر السر `ADMIN_CODE` في GitHub ثم شغّل سير العمل من تبويب Actions (أو عدّل `code` في `adminConfig/main` مباشرة) ← كل الأجهزة المفعّلة سابقًا تفقد الصلاحية فورًا، وتحتاج إدخال الكود الجديد.
- الكود لا يُقرأ من المتصفح إطلاقًا؛ التحقق يتم داخل قواعد Firestore.

## تغيير رابط الشعبة
غيّر `SECTION_SLUG` في GitHub Secrets وأعد تشغيل النشر (القواعد والكود يُضبطان تلقائيًا). البيانات مرتبطة بالمسار، أي أن الرابط الجديد يبدأ لوحة جديدة (القديمة تبقى في Firestore ويمكن نقلها يدويًا).

## كيف تعمل الإشعارات فعليًا
- الطالب يضغط زر الجرس ← "تفعيل الإشعارات" ← يوافق المتصفح ← يُحفظ رمز الجهاز في Firestore (لا يقرؤه أي متصفح).
- كل 10 دقائق يعمل `notifier/run.mjs` على GitHub Actions: يرسل إشعار **"جديد"** للتنبيهات المنشورة حديثًا، وتذكير **قبل 24 ساعة** و**قبل ساعتين** من الموعد. التوقيتات في `notifier/core.mjs` (`REMINDERS`).
- تغيير موعد تنبيه بعد إرسال تذكير: التذكيرات تُعاد تلقائيًا للموعد الجديد.
- رموز الأجهزة المنتهية تُحذف تلقائيًا.

**قيود حقيقية:**
- **iPhone/iPad**: لا تعمل الإشعارات إلا بعد "إضافة إلى الشاشة الرئيسية" من Safari (iOS 16.4+) ثم فتح الموقع من الأيقونة وتفعيل الإشعارات. الموقع يشرح هذه الخطوات للطالب تلقائيًا.
- **التأخير**: جداول GitHub Actions قد تتأخر 5–20 دقيقة وقت الضغط، فإشعار "جديد" ليس لحظيًا. لإشعار لحظي لاحقًا: انقل `runOnce` إلى Cloud Function (يتطلب خطة Blaze، وتكلفتها لهذا الحجم غالبًا صفر).
- المستخدم الذي رفض الإذن أو متصفحه لا يدعم الإشعارات يرى رسالة واضحة بالخطوات بدل الفشل الصامت.
- جداول GitHub تتوقف تلقائيًا إذا لم يحدث أي نشاط في المستودع لمدة 60 يومًا — أعد تفعيلها من تبويب Actions إن حصل.

## الاختبارات
```bash
npm run lint && npm run typecheck
npm test              # اختبارات الوحدة (الوقت، صيغ العربية، الأرشفة، جدولة الإشعارات)
npm run test:rules    # قواعد الأمان + سكربت الإشعارات على المحاكي
npm run test:e2e      # رحلة كاملة بمتصفحين: نشر ← ظهور بجهاز آخر ← رد ← تعديل موعد ← أرشفة تلقائية ← إدمن
```

## ما يُنصح بمراقبته أول أسبوع
- **Firebase Console ← Firestore ← Usage**: عدد القراءات اليومية (الحد المجاني 50 ألف/يوم).
- **GitHub ← Actions ← "إرسال الإشعارات"**: أن التشغيلات تنجح، وقيمة `tokens=` (كم جهازًا فعّل الإشعارات).
- كم طالبًا على iPhone ثبّت الموقع فعلًا (الإشعارات لن تصلهم بدونه).
- التنبيهات المكررة وعلامة "مكرر محتمل".
- ملاحظات الطلاب على نصوص العد التنازلي والتفاصيل.

## هيكل المشروع
```
src/                 الواجهة (React)
  data/api.ts        كل عمليات Firestore
  data/push.ts       تفعيل الإشعارات على الجهاز
  lib/               الوقت (توقيت الرياض)، صيغ العربية، ضغط الصور، منطق الأرشفة
  components/        البطاقات، الجدول، الشبكة، النموذج، الردود
public/sw.js         Service Worker (تثبيت PWA + استقبال الإشعارات)
firestore.rules.template   قواعد الأمان
notifier/            سكربت الإشعارات المجدول
.github/workflows/   النشر، الإشعارات، الاختبارات
```
